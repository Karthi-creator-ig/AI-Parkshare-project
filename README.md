# ParkShare | AI-Verified P2P Parking Marketplace

A high-performance, tech-forward marketplace application built to solve urban parking challenges in Tambaram, Chennai.

## 🚀 Professional Highlights

- **Full-Stack Architecture**: Built with **Next.js 15 (App Router)** and **Firebase**, featuring real-time Firestore synchronization and secure Authentication.
- **AI Verification System**: Leverages **Google Genkit** and Gemini Vision models to automatically analyze and verify parking spot photos, ensuring listing authenticity.
- **Geospatial Discovery**: Integrated **Leaflet** and **OpenStreetMap** for real-time user tracking, 5km radius filtering, and interactive location pinning.
- **Secure Transaction Flow**: Implemented a robust security model involving:
  - **Timed OTP Verification**: 10-minute expiring security codes for host-renter check-ins.
  - **Razorpay Simulation**: High-fidelity payment gateway simulation for a seamless Indian market experience.
- **Modern Tech Stack**: Uses **TypeScript**, **Tailwind CSS**, and **ShadCN UI** for a professional, responsive, and accessible user interface.

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (React 19)
- **Database/Auth**: Firebase (Firestore & Authentication)
- **AI/LLM**: Google Genkit (Gemini 1.5 Flash)
- **Maps**: Leaflet / OpenStreetMap
- **Styling**: Tailwind CSS + ShadCN UI
- **State Management**: React Hooks & Context API

## 📍 Local Focus
Optimized for the **Tambaram, Chennai** region with local currency support (₹) and regional coordinate centering.
